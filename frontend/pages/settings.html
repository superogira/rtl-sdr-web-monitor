⚙️ ตั้งค่าการเชื่อมต่อ

🎚️ สิทธิ์การบันทึกของผู้ใช้

ควบคุมว่าผู้ใช้ทั่วไป (role=user) จะสามารถกดบันทึกเสียงแบบ manual ได้หรือไม่

ผู้ดูแลระบบ (admin) สามารถบันทึกได้เสมอ ไม่ว่าจะตั้งค่านี้อย่างไร

🎙️ การบันทึกเสียงความถี่กลาง (Center) อัตโนมัติ

บันทึกเสียงที่ ความถี่กลาง (Center Frequency) ที่ตั้งไว้ในระบบอัตโนมัติเมื่อมีสัญญาณเข้าเกณฑ์ Squelch (ทำงานเป็น background ไม่ต้องมีใครฟังสด)

แยกจากการอัดเสียงของผู้ใช้ตอนฟังสด (ซึ่งเปิด/ปิดได้ที่ Dashboard รายบุคคล)

ค่า Silence / Min / Max Duration ด้านล่างนี้ใช้ ร่วม กับทั้งการบันทึกกลางอัตโนมัติและการอัดอัตโนมัติของผู้ใช้ตอนฟังสด

ค่าต่ำ = ไวต่อสัญญาณ (บันทึกง่าย อาจเก็บเสียงรบกวน) · ค่าสูง = เข้มงวด (บันทึกเฉพาะสัญญาณแรง)

📡 การตั้งค่าการอัดเสียงของอุปกรณ์

ตั้งค่าให้อุปกรณ์ SDR อัดเสียงที่ความถี่ที่ต้องการอัตโนมัติ (ทำงานเป็น background)

อุปกรณ์หนึ่งใช้ได้ครั้งละหนึ่งการตั้งค่าการอัด และสามารถอัดได้หลายความถี่พร้อมกันในช่วงความถี่ที่กำหนด

เวลาในตารางเวลาใช้ เขตเวลาของเซิร์ฟเวอร์ (ตั้งค่าได้ที่ส่วน "เขตเวลาของเซิร์ฟเวอร์" ด้านล่าง)

🌍 เขตเวลาของเซิร์ฟเวอร์

กำหนดเขตเวลาที่ใช้สำหรับตารางเวลาการอัดเสียงของอุปกรณ์ (เช่น 08:00–10:30 จะหมายถึงเวลาในเขตเวลานี้)

🗂️ การเก็บรักษา (Retention)

ระบบจะลบรายการเก่าอัตโนมัติตามเงื่อนไขด้านล่าง (อันไหนเข้าเงื่อนไขก่อนก็ลบก่อน) ค่า 0 = ไม่จำกัด

📊 เวลาการถอดเสียง (STT Usage)

ความยาวเสียงรวมที่ถอดได้ แยกตามผู้ให้บริการ (นาที)
ไม่มีข้อมูล
ความยาวเสียงรวมที่ถอดได้ของ Whisper แยกตามโมเดล (นาที)
ไม่มีข้อมูล Whisper
อัตราส่วนเวลารอถอดเสียงต่อความยาวเสียง แยกตามโมเดล Whisper (RTF)
ไม่มีข้อมูล Whisper

📝 Speech-to-Text (Global)

ค่าเหล่านี้เก็บในฐานข้อมูล ใช้ร่วมกันสำหรับผู้ใช้งานทุกคน

Whisper Local API Settings

เชื่อมต่อกับ faster-whisper-server บนเครือข่ายท้องถิ่น (Gradio API)

เช่น Systran/faster-whisper-small, Systran/faster-whisper-medium

0.0 = แม่นยำที่สุด (greedy), ค่าที่สูงขึ้น = สร้าสรรค์มากขึ้น (sampling)

ย่อขนาดไฟล์ก่อนส่งไปถอดเสียง → ประหยัด bandwidth & เร็วขึ้น

Groq Whisper API Settings

ใช้ Groq OpenAI-compatible Whisper API สำหรับถอดเสียงบน Cloud

ปล่อยว่างถ้าไม่ต้องการเปลี่ยนค่าที่ตั้งไว้

เลือกโมเดล Whisper ที่ Groq ให้บริการ

Groq รองรับไฟล์เสียงหลายรูปแบบ เช่น WAV/FLAC/MP3 — MP3 ประหยัด bandwidth ที่สุด

MaxPlus AI Settings

ใช้ MaxPlus AI API (api.maxplus-ai.cc) OpenAI-compatible สำหรับถอดเสียงบน Cloud

ปล่อยว่างถ้าไม่ต้องการเปลี่ยนค่าที่ตั้งไว้

เลือกโมเดลถอดเสียงที่ API key ของคุณใช้ได้ (ดึงจาก GET /v1/models)

MaxPlus AI รองรับไฟล์เสียงหลายรูปแบบ (ไม่เกิน 25 MB) — MP3 ประหยัด bandwidth ที่สุด

Speechmatics API Settings

ปล่อยว่างถ้าไม่ต้องการเปลี่ยนค่าที่ตั้งไว้

Speechmatics รองรับ WAV/FLAC/MP3 — MP3 ประหยัด bandwidth ที่สุด

Azure Speech API Settings

Leave empty to keep existing key

e.g. southeastasia, eastasia, eastus

⚠️ Azure Speech SDK รองรับเฉพาะ WAV/PCM — MP3/FLAC จะถูกแปลงเป็น WAV อัตโนมัติ

Language maps from above (th -> th-TH, en -> en-US).
Create resource at Azure Portal -> Cognitive Services -> Speech.

🎨 Theme หน้าจอ

เลือกรูปแบบการแสดงผลของ Dashboard

Classic = สไตล์เดิม (เข้ม แบบ operations desk)

V2 (Analog Radio) = ปุ่มนูน 3D เหมือนวิทยุจริง, จอ VFO บุ๋มแบบ LCD, ฟอนต์ 7-segment

🌊 Waterfall ความเร็วการเลื่อน

ความเร็ว = จำนวนบรรทัดที่เพิ่มต่อเฟรมข้อมูล spectrum (1x = ช้า, 4x = เร็วมาก)

📊 FFT Size (ความละเอียด Waterfall)

ขนาด FFT = จำนวน bins ในแต่ละบรรทัดของ waterfall

ค่ามาก = ละเอียดขึ้น แต่ใช้ CPU/Bandwidth มากขึ้น

⚠️ 4096 bins ใช้ CPU และ Bandwidth สูง อาจทำให้เครื่องช้าได้

🎨 ช่วงสี Waterfall (dB)

ค่า dB ต่ำสุด-สูงสุดที่จะแสดงเป็นสี ค่าที่ต่ำกว่าจะเป็นสีดำ ค่าที่สูงกว่าจะเป็นสีขาว

ใช้กับปุ่ม 🎚️ AUTO: ระบบหาค่า noise floor แล้วตั้งค่าต่ำสุดให้ต่ำกว่านั้น 10 dB และค่าสูงสุด = ค่าต่ำสุด + ค่านี้

⚙️ นโยบายระบบ (System Policy)

การตั้งค่านโยบายการใช้งานของระบบ — สำหรับผู้ดูแลระบบเท่านั้น

กำหนดขอบเขตการ tune VFO:
max_offset = min(sample_rate × ratio, sample_rate/2 − channel_bw/2)
พจน์หลังกันไม่ให้ช่องสัญญาณกว้าง (เช่น 50k/200k) ล้นขอบ Nyquist แล้ว alias กลับเข้ามา
ค่าต่ำ = ปลอดภัย (ลด aliasing ใกล้ขอบ), ค่าสูง = ขยายช่วงฟังได้กว้างขึ้น

จำกัดจำนวนผู้ใช้ที่ฟังเสียงสดพร้อมกัน (1–128)

แต่ละผู้ฟังใช้ CPU 1 demod thread — ค่าสูงขึ้นต้องเซิร์ฟเวอร์แรงขึ้น
